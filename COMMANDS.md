Notes:
an OR indicates that both or all wordings shown here should work the same way

Commands we want in the game:

look
→ can target the player, npcs, exits, the current location (ground), the sky, and up

get OR take
→ acquires item that is described to be there and can be taken. If no such item exists, system message: you can’t get that (or similar)

open
→ opens doors, chests, windows, etc. Things that make sense to open. If player attempts to open something that can’t be opened, like an NPC, system message: Doesn’t seem like that can be opened (or similar)

close
→ closes stuff that can be opened.

examine OR study OR investigate
→ skill; increases with use. More skill = more information. Items will therefore need multiple descriptions of increasing clarity, with a final explanation that indicates the top tier has been discerned

learn
→ skill; usable only on recipes, songs, etc. Tiers 1-5; players start able to learn tier 1, but get better as they learn more stuff. Fail messages indicate that further study will eventually succeed. No RNG here; simply do you have the skill to do it yet, or not. 
e.g.: learn kiss → this is a tier 1 spell, so the text reads: You take the time to learn the kiss spell. You are confident you can replicate these actions. 
learn dance → this is a tier 2 spell, but the player is still tier 1, so the text reads: You review the writings on the dance spell. It seems a little beyond your current abilities at the moment. 
versus if they were tier 2: You take the time to learn the dance spell. You are confident you can replicate these actions. 

talk to (NPC)
→ opens the Conversation window. In conversation, I think it starts off like:
‘You approach (NPC).’ 
And then you get a fresh description of the NPC’s current like, mood / attitude because you’re talking to them, e.g.:
→ talk to Nona
You approach Nona. She is shifting uneasily from foot to foot. 

Within the conversation window, I’m not sure if we should include prompts? I like the idea of letting the player fumble around. But you can probably “ask about” (gain information); “compliment” (be nice to them; reparative); “insult” (be rude to them; won’t be able to take a quest if you do this too much); “agree” (take a quest); “disagree” (refuse to take a quest you don’t like the sound of). I know it’ll be more writing to make it more complex, but I think having some d&d style freedom to be silly with the NPCs would appeal to me.

say
→ Just talking out loud. Hidden NPCs might respond to this, and/or we might have a LOTR style ‘say the magic word to open a place’ puzzle somewhere.

jump → for if we design some obstacles like fences, or small gaps, or even puddles they don’t wanna get their feet muddy in

climb → to go to second floor without taking the stairs, etc., perhaps from outside. May also circumvent fence type obstacles or make it possible to explore trees, etc.
